# Stream Deck Plugins

A collection of Elgato Stream Deck plugins. Each plugin lives in its own folder with its own `package.json`,
sources and `.sdPlugin` bundle.

| Folder | Plugin | What it does |
| --- | --- | --- |
| [`sonos/`](sonos/) | Sonos (`com.igorstefus.sonos`) | Play/pause, group and volume keys for Sonos speakers picked in each key's settings. Local network only, no account. |
